## 9. Критерии успешности

### 9.1. Обязательные проверки (Critical)

Все эти проверки должны пройти успешно:

- [ ] Проект компилируется без ошибок
- [ ] Login Server запускается и принимает подключения
- [ ] Game Server запускается и принимает подключения
- [ ] Подключение к MySQL работает (Login и Game)
- [ ] Шифрование пакетов работает корректно
- [ ] Клиент может пройти аутентификацию
- [ ] Клиент может войти в игровой мир

### 9.2. Приемлемые уровни ошибок

| Категория | Допустимый уровень | Действие при превышении |
|-----------|-------------------|------------------------|
| Ошибки компиляции | 0 | Блокирует миграцию |
| Ошибки runtime (Critical) | 0 | Блокирует миграцию |
| Ошибки runtime (High) | < 5 | Требуется исправление |
| Предупреждения компиляции | < 50 | Рекомендуется исправить |
| Тесты xUnit (Failed) | 0 | Блокирует миграцию |
| Утечки памяти | < 10% за час | Требуется investigation |

### 9.3. Перформанс критерии

| Метрика | Минимальное требование | Целевое значение |

## 11. Команды для быстрого тестирования

### 11.1. Полный цикл тестирования

```bash
#!/bin/bash
# quick-smoke-test.sh

echo "=== AAEmu .NET 10.0 Smoke Test ==="

# 1. Проверка SDK
echo "[1/8] Checking .NET SDK..."
dotnet --version

# 2. Восстановление пакетов
echo "[2/8] Restoring packages..."
dotnet restore

# 3. Компиляция
echo "[3/8] Building..."
dotnet build -c Release

# 4. Тесты
echo "[4/8] Running tests..."
dotnet test AAEmu.Tests

# 5. Публикация
echo "[5/8] Publishing..."
./publish.sh

# 6. Docker build
echo "[6/8] Building Docker images..."
docker-compose build

# 7. Docker run
echo "[7/8] Starting Docker containers..."
docker-compose up -d

# 8. Проверка
echo "[8/8] Checking containers..."
docker-compose ps

echo "=== Smoke Test Complete ==="
```

### 11.2. Проверка логов

```bash
# Login Server logs
docker-compose logs -f login

# Game Server logs
docker-compose logs -f game

# MySQL logs
docker-compose logs -f db
```

### 11.3. Очистка

```bash
# Остановка контейнеров
docker-compose down
```
